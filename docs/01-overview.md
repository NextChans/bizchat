# 01. 개요

## 배경

SK텔레콤 비즈챗(소상공인 광고문자 발송 서비스)을 캐시노트(KCD) 앱 안의 배너로 노출해 가맹점주를 유입시킨다.
협업 채널: Slack `#agenda-sk비즈챗-협업` (2026-10-21 협조 요청·회신).

KCD 측에 요청한 세 가지와 회신(2026-10-21):

| 요청 | 목적 | 회신 요지 |
| --- | --- | --- |
| 1. 건설업·제조업 가맹점 정보 | 업종별 광고문자 템플릿 제작(외식·서비스업은 기존 양식 있음). 필요 정보: 대분류/소분류/가맹점명 | 업종 특정 없이도 가맹점 정보 제공은 KCD 개발 쪽과 논의. 데이터가 많으면 **최근 1개월 내 1회 이상 접속 유저** 기준으로 추출해도 됨 |
| 2. 자동입력용 가입 정보 | 배너 진입 시 가게명·연락처·업종·동네명·주소 자동입력 → 입력 오류 감소, 전환율·작성 시간 개선 | **상호·업종·주소는 개인정보 검토상 전달 가능.** 그 외 개인정보 포함 항목은 사업적으로 이견 없으나 개발 쪽과 논의 |
| 3. 캐시노트 앱 푸시 연동 | 진행 상황 알림 | **외부 서비스 앱푸시는 사례 없음·어려움**(자사 서비스로 오인). API 연동으로 진행 상황을 앱에 표현하는 건 이견 없음(개발 논의) |

→ 이 저장소는 2번(자동입력)을 받는 **브릿지 페이지**와, 그 뒤 발송 결제까지를 다룬다.
푸시(3번)는 범위 밖. 진행 상황 표시가 필요하면 파트너가 브릿지 상태 API 를 조회하는 방식으로 별도 설계.

## 범위

| 포함 | 제외 |
| --- | --- |
| 파트너 POST 진입(서명 검증) · 업종별 템플릿 작성 화면 | 비즈챗 화면(비즈챗에는 화면이 없음, 서버 간 API 만) |
| 발송 대상 규모 선택 · 비즈챗 견적 | 실제 대상 고객 추출·발송(비즈챗) |
| KPN 결제창 · 승인 · 보상 취소 · 조회 | 가상계좌(입금 통보 후 결제 완료) · 부분취소 · 환불 요청 |
| 비즈챗 발송 요청(서버 간) | 앱 푸시, 발송 결과 수신(미정, 04 참고) |

## 시스템 구성

```
 캐시노트 앱(웹뷰)
   │ ① 배너 클릭: 파트너 서버가 서명한 form 을 auto-submit
   ▼
 ┌──────────────────────── bizchat 브릿지 (Next.js 16, App Router) ────────────────────────┐
 │ /bridge/entry  →  /bridge (작성)  →  /bridge/send (대상·금액)  →  결제창  →  /bridge/pay/… │
 │      │                 │ 초안 보관                │ ② 견적 API              ▲ ④ returnUrl    │
 └──────┼─────────────────┼──────────────────────────┼─────────────────────────┼──────────────┘
        │                 ▼                          ▼                         │
        │          [ad_drafts / orders]      비즈챗 서버 (API only)      KPN 결제서버
        │                                     ⑤ 발송 요청 ◀── 승인 후 ──  ③ SDK 결제창, 승인·취소·조회
```

| 상대 | 방식 | 주고받는 것 |
| --- | --- | --- |
| 파트너(캐시노트) | 브라우저 form POST, HMAC 서명 | 가맹점 정보 |
| KPN 결제서버 | SDK 결제창 + 서버 JSON API | 결제창 호출, 인증 결과, 승인, 취소, 조회 |
| 비즈챗 | 서버 간 API | 대상 규모, 견적, 발송 요청 |

## 화면 흐름

1. **가게 정보 확인** (`/bridge` 1단계): 파트너 정보로 채움. 가게명·동네명·전화번호 필수, 주소 선택. 업종은 읽기 전용
2. **메시지 작성** (`/bridge` 2단계): 업종별 템플릿 3종 중 선택(추천 배지), 칩을 눌러 빈칸 입력, 링크 옵션, 바이트 카운터
3. **발송 대상** (`/bridge/send`): 300~3,000명 선택지, 단가·공급가·부가세·결제금액 표시 → 결제하기
4. **결제창** (KPN, 페이지 이동 방식)
5. **결과** (`/bridge/pay/result/{주문번호}`): 상태별 안내, 보류 건 "다시 확인하기"

시안: 캐시노트 "우리가게 광고 만들기" 화면(2단계 진행바, `(광고)[SKT]` 머리말, 칩 편집, `무료 수신거부 1504`).
